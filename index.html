How inverse Sigh actually works (and what it cannot know)

Sigh forward: x(n+1)=α x(original)+(1−α) F_EQ[x(n)]. For each Fourier mode the same real gain g is applied, so its transfer after the stated number of passes obeys h(n+1)=α+(1−α) g h(n), h(0)=1. The inverse estimates the effective transfer from aligned source and target Fourier coefficients, inverts that scalar recurrence, then searches for ten control values whose interpolated curve agrees with the evidence.

For a single pair, no signal at a frequency means no knowledge of the gain there. High pass counts can make several different gains indistinguishable. Phase changes, clipping, shifting, resizing, nonlinear edge-aware filters, noise and incorrect α/pass assumptions violate this ten-band model. An arbitrary changed picture is not evidence for a unique EQ. Images are converted to 128×128 centered grayscale; imported pairs must already be aligned. The synthetic target is computed in floating point (no hidden JPEG clipping), while display images are clamped only for viewing.

Unlike Luotain2's general spatial-term grammar, this is a deliberately constrained ten-band inverse problem. The residue-guided search is real, but this is not a claim that the system discovers arbitrary physics.
